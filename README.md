[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](https://choosealicense.com/licenses/mit/)

## Description

My portfolio website, built with React, TypeScript, and Vite. It's a single-page site with a hero intro, career highlights, a skills toolkit, an about/bio section, testimonials, and contact info, plus dedicated pages for a project archive and an embedded résumé. There's also a fun dark mode option!
